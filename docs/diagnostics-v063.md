# نسخهٔ ۰٫۶۳: گزارش دقیق و ثبت مستقل نمونه‌ها

قواعد ورود و خروج نسخهٔ ۰٫۶۲ تغییر نکرده‌اند. گزارش اکنون نام جایگزین،
سقف واقعی ۴ سنت، یک ورود در هر بازهٔ ۱۵ دقیقه و نگهداری سه بازه را نشان
می‌دهد. تنظیمات خروج سریع قدیمی به‌صراحت فقط مربوط به موقعیت‌های قدیمی‌اند.
وضعیت انتظار الگو روی نمودار دیده می‌شود؛ برآورد حجم قبلی تأیید ورود نیست.

## ثبت نمونه

قید قدیمی `UNIQUE(captured,symbol)` باعث حذف نمونهٔ دوم برای یک نماد در
همان ثانیه می‌شد، حتی وقتی شناسهٔ درخواست متفاوت بود. این ایراد در آزمون
دو درخواست مین و اسمال بازتولید و اصلاح شد. نتیجهٔ «ذخیره نشده» در گزارش
کاربر می‌تواند از این برخورد باشد؛ لاگ زندهٔ سرور کاربر در دسترس نیست.

مهاجرت پایگاه داده در تراکنش انجام می‌شود؛ ردیف‌ها، شناسه‌ها، ستون‌های
اضافی، نمایه‌ها و محرک‌های موجود حفظ می‌شوند. شناسهٔ نمونه همچنان یکتا است.
نمونه‌های قدیمی بدون شناسه همان حذف تکراریِ قبلی را حفظ می‌کنند. داده‌های
حذف‌شده در گذشته با این اصلاح بازیابی نمی‌شوند.

پاسخ سرور و گزارش ربات وضعیت ثبت را جداگانه نمایش می‌دهند:
`saved`، `history_disabled`، `duplicate_or_ignored` یا `storage_error:<type>`.
سرورهای قدیمی که این فیلد را ندارند همچنان قابل استفاده‌اند؛ علت خطا در
آن‌ها نامشخص نمایش داده می‌شود. خطای ثبت، تصمیم معامله را تغییر نمی‌دهد.


## بررسی ساعت معامله

فرضیهٔ بهتر بودن صبح تا ظهر و بدتر بودن بعدازظهر باید بر اساس ساعت **ورود**
به وقت تهران، سود خالص پس از هزینه‌ها و نسخهٔ ربات بررسی شود.
فایل قدیمی ارسالی تا ۲۹ سپتامبر در بررسی سلامت SQLite ناسازگار بود؛ جدول
ساعتی اولیهٔ استخراج‌شده از آن قابل اتکا نیست و مبنای تغییر ساعت اجرا نشد.
این مشاهده دربارهٔ فایل قدیمی است، نه تشخیص خرابی پایگاه دادهٔ فعال کاربر.

مهاجرت ابتدا سلامت پایگاه داده را بررسی می‌کند و در صورت خطا بدون حذف
ردیف‌های قبلی متوقف می‌شود. وضعیت ثبت و لاگ سرور خطا را نشان می‌دهند.
برای تهیهٔ یک نسخهٔ تازه و سازگار از پایگاه دادهٔ فعال، از رابط پشتیبان‌گیری
SQLite استفاده کنید؛ کپی سادهٔ فایل فعال ممکن است محتوای WAL را جا بیندازد:

```bash
docker compose exec -T model python - <<'PYBACKUP'
import sqlite3
source = sqlite3.connect('file:/data/ramon_history.sqlite3?mode=ro', uri=True)
target = sqlite3.connect('/data/ramon_audit_fresh.sqlite3')
source.backup(target)
print(target.execute('PRAGMA integrity_check').fetchall())
target.close()
source.close()
PYBACKUP
```

اگر نتیجه `ok` بود، فایل `data/ramon_audit_fresh.sqlite3` را برای تحلیل
بفرستید. هیچ محدودیت ساعت تازه‌ای اعمال نشده است.
