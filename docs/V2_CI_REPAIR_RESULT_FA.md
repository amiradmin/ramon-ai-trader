# نتیجه اصلاح تست‌های V2 — ۱۰ اکتبر ۲۰۲۶

شاخه: `feature/v2-eight-capability-redesign`؛ مبنای کد پیش از اصلاح: `e068f2d`.

## مشکل و اصلاح

اجرای کامل ابتدا با سه خطای collection متوقف شد: نبود pandas در وابستگی dev و importهای منسوخ ShadowCoordinator/TimesFM3Shadow. پس از رفع آن‌ها، ۴۲ شکست و ۴۸۴ موفقیت ثبت شد. شکست‌ها با تغییرات قبلی معماری Direction AI عملیاتی، TimesFM آزمایشی، نسخه و داشبورد EA، قرارداد تاریخچه و مسیرهای اجرای داشبورد تطبیق داده شدند.

- pandas به extra توسعه اضافه شد؛ هیچ کتابخانه مدل سنگینی برای تست دانلود نشد.
- تست‌های هماهنگ‌کننده از ماژول واقعی مورد استفاده سرور، `direction_roles`، استفاده می‌کنند. مهاجرت بسته‌های schema 1 همچنان پوشش دارد.
- تست آموزش ثابت می‌کند ناموفق بودن promotion gate، اشاره‌گر قبلی Direction AI را تغییر نمی‌دهد.
- ۲۱ سناریوی جدید، داده مفقود/نامعتبر متخصصان و ناکافی بودن فیلدهای قدیمی shadow برای تصمیم زنده را بررسی می‌کنند.
- آزمون HTTP نقش‌های عملیاتی نشان می‌دهد کیفیت برابر BUY/SELL حتی با پیش‌بینی پایه BUY به WAIT می‌رسد.
- آزمون‌های خاص مسیر قدیمی به‌صراحت AI Engine را خاموش می‌کنند؛ تست مسیر reversal قدیمی همچنین ROLE_MODE=live دارد. این تنظیمات فقط در fixtureهای تست‌اند.
- قراردادهای ساختاری EA با نسخه 0.59.5 و رابط فعلی همگام شدند. تست چیدمان، فاصله ردیف‌های واقعی را به‌جای مختصات منسوخ بررسی می‌کند.
- آداپتور C++ رفتار موجود داشبورد را صریحاً ثبت می‌کند: مسیر داشبورد از خبر/وقفه محلی/شمارش روزانه عبور می‌کند؛ محدودیت زیان حساب، تازگی قیمت و spread همچنان بررسی می‌شوند. این رفتار در این اصلاح ایجاد نشده و به معنی تأیید آمادگی زنده نیست؛ ارزیابی سیاست داشبورد هنوز باقی است.
- CI دارای مهلت ۱۵ دقیقه و حداکثر دو thread برای OpenMP/OpenBLAS شد.

## نتیجه محلی

```text
Python 3.13.7 / NumPy 2.5.3 / pandas 3.0.6 / scikit-learn 1.9.1
```

فرمان بازتولید از ریشه پروژه:

```bash
env -u PYTHONPATH PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
  OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
  .venv/bin/python -m pytest -q
```

این مجموعه شامل تست Python، HTTP/SQLite محلی، قراردادهای ساختاری و آداپتورهای شبیه‌سازی‌شده C++ است؛ نتیجه تست بومی بروکر یا معامله واقعی نیست. اجرای HTTP به امکان ایجاد سوکت localhost نیاز دارد. خطای سوکت sandbox به‌عنوان خطای محصول تفسیر نشد.

## محدودیت و انتشار

در این اصلاح، `mt5/Ramon.mq5` و منطق Python تولید تغییر نکردند. سقف‌های ریسک حساب سنت، تنظیم MoneyUnitsPerUSD و پیش‌فرض غیرفعال معاملات زنده حفظ شدند. هیچ سفارش، بستن پوزیشن یا بازکردن قفل Stop Out انجام نشد.

مقصد PR شماره ۷۱ از شاخه V3 به main اصلاح شد و PR پیش‌نویس باقی ماند. اجرای CI در GitHub جداگانه باید نتیجه دهد؛ موفقیت محلی معادل موفقیت CI نیست.

ماندگاری قفل در Restart بدون سفارش قبلاً تأیید شده؛ اجرای بومی fixture بازیابی Stop Out خاموشی، Guardian دمو با تأیید بروکر، بررسی هم‌زمانی چند EA و ارزیابی سوددهی خارج از نمونه همچنان کامل نیستند. تصمیم انتشار عملیاتی و Merge به main: **No-Go تا تکمیل معیارهای پذیرش**.
