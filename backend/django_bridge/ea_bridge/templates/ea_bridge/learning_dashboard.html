Code-backed analyzers

These are the analysis components in ramon_pipeline/learning/. Unlike ARIMA/SARIMA/Ridge/Random Forest, they are not independently trained ML models: they run on trade outcomes and current evidence. Their last execution is the dashboard analysis refresh, not a model-training timestamp.

Component registry

OutcomeCollector

outcome_collector.py

Validates and records completed trade outcomes through the SignalFlow outcome store.

Trigger: each received outcome

LearningEngine

engine.py

Orchestrates the analysis components and exposes summary, review, and observe operations.

Trigger: dashboard analysis request

PerformanceAnalyzer

performance_analyzer.py

Calculates aggregate trade performance using the established learning statistics.

Output: analysis.performance

DecisionAnalyzer

decision_analyzer.py

Measures outcome-to-decision attribution and linked/unlinked coverage without guessing missing links.

Output: analysis.decisions

EntryExitAnalyzer

entry_exit_analyzer.py

Summarizes MAE, MFE, entry/exit efficiency, spread, and slippage when broker data exists.

Output: analysis.entry_exit

RegimeAnalyzer

regime_analyzer.py

Segments observed trade performance by market regime.

Output: analysis.regimes

MistakeDetector

mistake_detector.py

Finds statistically supported patterns and keeps findings as hypotheses, not automatic rules.

Output: analysis.mistakes

StrategyEvaluator

strategy_evaluator.py

Compares tagged strategy profiles and enforces minimum sample safeguards.

Output: analysis.strategies

OptimizationEngine

optimization_engine.py

Compares baseline and candidate evidence offline; requires sufficient trades, improved expectancy, and no worse drawdown.

Trigger: explicit candidate evaluation · not auto-run

RecommendationEngine

recommendation_engine.py

Converts review findings into deduplicatable recommendations for human review.

Trigger: Generate recommendations

Learning contracts

models.py

Defines typed OutcomeRecord and AnalysisReport data contracts; it is not a predictive model.

Role: typed data structures

Package exports

__init__.py

Exports the learning engine, analyzers, recommendation and optimization components as the package API.

Role: module interface

Analysis execution status will appear after the first successful dashboard refresh. OptimizationEngine is currently a callable offline evaluator, not part of the automatic analyze() pass. None of these components can alter live strategy parameters or authorize orders.
